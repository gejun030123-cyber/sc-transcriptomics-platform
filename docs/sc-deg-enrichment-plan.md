# 人类单细胞差异表达与通路富集规划

## 当前已实现

平台只接受 Human 通路富集。差异分析按问题和统计单位分开，避免把
细胞数误当作生物学重复数。

| 研究问题 | 平台入口 | 统计单位与结论边界 |
| --- | --- | --- |
| 同一样本的不同簇 | 细胞级探索性比较：`within_sample_clusters` | 细胞；用于 marker/状态描述，不报告生物学样本推断。 |
| 不同样本的同一簇 | 细胞级探索性比较：`between_samples_within_cluster`；有条件组重复时用 per-cluster pseudobulk | 单样本对只能描述；正式条件结论使用样本×簇 pseudobulk。 |
| 不同样本全部细胞 | 细胞级探索性比较：`between_samples_all_cells`；有条件组重复时用 all-cells pseudobulk | 整体 pseudobulk 也可能受细胞组成变化影响，需结合比例分析解释。 |
| 不同条件 | 细胞级条件比较用于探索；pseudobulk 用于正式结论 | 前者不把细胞当重复；后者以独立生物学样本为重复。 |

所有细胞级 log2FC 均从 `layers['counts']` 临时重建 library-size
normalization + log1p 表达层。Pearson residual 不再直接用于计算或解释
fold change。

Pseudobulk 默认使用 DESeq2。若 `batch` 与 `condition` 完全混杂，或
DESeq2 拟合失败，对应单元会明确标记为不可运行/模型失败；不会自动切换
到 Welch。Welch 仅在用户明确选择时作为近似样本级分析，并在审计中标出
未建模协变量。

富集必须从页面中选择一个已经完成的 DEG 任务。系统读取该任务记录的
内部结果和 AnnData 版本，拒绝混用，不再按目录中“最新 CSV”推断来源。

## 批量基因集富集

对于同一个已选定的 DEG 比较，Bulk 富集页面支持在一次任务中选择多个
标准 Human 数据库（GO BP/MF/CC、KEGG、Reactome、WikiPathways）。每个
数据库仍是独立的统计单元：ORA 使用同一 DEG 的受检基因背景但按本库的
映射覆盖率重新计算，GSEA 使用同一完整排序表；BH/FDR 仅在“比较 × 数据库
× 方向”内校正，概览不再进行跨数据库校正或得出统一显著性结论。

任务会为每个数据库保存完整结果、映射 QC、基因集版本/checksum 与方法说明，
并额外输出仅包含本任务子结果的整合表、数据库汇总表和多数据库概览。某一库
不可用或没有可检验通路时，该库会标记失败，其余库继续运行。批量结果写入任务
专属目录；不会扫描或混入项目中历史富集结果。为避免图形爆炸，批量子运行只保留
每库主图和任务级概览；完整 Nature 套图仍适用于单库运行。自定义 GMT 保留在
兼容单库模式，以保证输入快照和解释边界清晰。

单细胞富集原本已支持多个本地库；页面改为复选选择器，仍只接受平台缓存或当前
项目内、非符号链接的 GMT/TXT 文件。

## 输出原则

默认结果是图、结果摘要和 JSON 统计审计。完整 DEG/富集表仅作为受控的
内部下游输入，不在当前单细胞界面生成或下载。兼容用的“批量单细胞 CSV
导出”保留在模块注册表中供旧项目调用，但已从主单细胞流程和 AI 模块列表
隐藏。

## 后续增强（不阻断当前使用）

1. 增加 `condition × cluster` 交互模型，专门回答“某个簇的条件效应是否
   显著不同于其他簇”。它不能伪装成普通两组 DEG。
2. 在结果页增加可筛选的基因/通路表格视图，按需下载而不是默认生成大量
   平铺文件。
3. 为每个内部 DEG 文件记录输入 AnnData 内容哈希和完整软件版本快照。

## 明确延期：元细胞

元细胞将相近细胞聚合以降低稀疏性，适合状态连续谱、轨迹和平滑展示；
它不是生物学重复，不能替代 sample×cluster pseudobulk，也不能把多个
元细胞当成多个独立样本。本阶段不加入元细胞，待有明确轨迹/状态平滑需求
时再单独设计其构建、质控和与 pseudobulk 的边界。
